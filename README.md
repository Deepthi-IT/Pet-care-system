# Pet Care Management System

This is a full-stack web application developed as a university group project. This repository contains the full project code, and it has been imported to showcase my individual contribution to the team effort.

## 🌟 My Core Contribution (Individual Role)
While this was a collaborative group project, my primary responsibility and sole ownership was designing and developing the **Appointment Management Module** from scratch (both backend and frontend).

### Key Features I Personally Implemented:
* **Appointment Scheduling:** Implemented functionality for pet owners to book, reschedule, and cancel appointments with veterinarians.
* **Automated Booking & Availability Check:** Developed backend logic to check real-time availability of time slots to prevent double-booking.
* **Status Tracking Dashboard:** Created an interactive dashboard using React to let admin/staff view, approve, complete, or reject pending appointments easily.
* **Database Design:** Designed and optimized MySQL database tables for appointments, doctor schedules, and pet owner profiles.

## 🛠️ Tech Stack I Used
* **Backend:** Java, Spring Boot, Maven
* **Frontend:** React.js, HTML5, CSS3, Bootstrap
* **Database:** MySQL

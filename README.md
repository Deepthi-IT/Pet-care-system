Pet Care Management System
This is a full-stack web application developed as a university group project.

👥 Group Project Disclaimer
This repository is a clone of our original campus group project. I have imported it here to showcase my individual contribution to the project.

🌟 My Core Contribution
My primary responsibility in this project was developing the Appointment Management Module (both backend and frontend).

Key features I implemented:

Appointment Scheduling: Implemented functionality for pet owners to book, reschedule, and cancel appointments with veterinarians or groomers.
Automated Booking & Availability Check: Developed backend logic to check real-time availability of time slots to prevent double-booking.
Status Tracking Dashboard: Created an interactive dashboard using React to let admin/staff view, approve, complete, or reject pending appointments easily.
Database Design: Designed and optimized MySQL database tables for appointments, doctor schedules, and pet owner profiles.

Frontend: React.js, HTML5, CSS3, Bootstrap
